# HRMS Project

Human Resource Management System built using Python.
Manages employee data, attendance, and basic HR operations.

## Features

* Add, update, and delete employee records
* Track attendance
* Store employee details securely
* Simple and easy-to-use interface

## Tech Stack

* Python


## Project Structure

* main.py → Entry point
* models/ → Data handling
* templates/ → UI files
* static/ → CSS/JS

## How to Run

1. Clone the repository
2. Open project folder
3. Run:
   python main.py
